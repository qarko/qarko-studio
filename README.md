## 🛠️ 품질 검증 및 기술 스펙

- **100% 무의존 자립 실행**: 빌드나 서버 없이 단독 HTML/CSS/JS로 즉시 렌더링
- **WCAG 웹 접근성 통과**: axe-core 접근성 위반 0건 준수
- **64개 해상도 검증**: Chromium/WebKit 기반 320px ~ 1920px 완벽 반응형 대응
- **Zero AI Slop**: 교과서식 AI 주석 및 불필요한 번들 제거, 프론트엔드 개인정보 노출 차단

